# 🎬 Netflix Movie Explorer

A React-based movie application that allows users to explore popular movies, search by title, save favorites, and get AI-powered movie recommendations based on their mood.

## 🚀 Features

- Browse popular movies
- Search movies
- Add/remove favorites
- AI Mood Search (Gemini AI)
- Infinite scrolling
- Responsive UI

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript
- React Router
- TMDB API
- Google Gemini AI

## ⚙️ Installation

```bash
git clone https://github.com/abhi19-code/netflix-clone.git
cd netflix-clone
npm install
npm run dev
```
